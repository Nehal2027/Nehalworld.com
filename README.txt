# nehal World Website

এই ফোল্ডারে একটি মোবাইল-ফ্রেন্ডলি বাংলা ওয়েবসাইটের ৩টি মূল ফাইল আছে:

- index.html
- style.css
- script.js

## নিজের তথ্য বসানো
index.html ফাইলে:
- "নেহাল খান" → নিজের নাম
- Facebook/WhatsApp/Messenger href → নিজের বৈধ লিংক
- Button-এর লেখা → নিজের প্রয়োজন অনুযায়ী পরিবর্তন করুন

## অনলাইনে ফ্রি প্রকাশ
GitHub Pages-এর মাধ্যমে static website প্রকাশ করা যায়।
